Overview

This repository contains the assignments completed as part of the Solidity Sprint 2026 at Atria University.

The sessions cover fundamental Solidity programming concepts and gradually introduce more advanced blockchain development topics, including:

Solidity contracts and state variables
Functions and reference types
Structs, enums, and mappings
Modifiers and access control
Interfaces and events
Ether deposits and withdrawals
Reentrancy protection
ERC-20 token development
ERC-721 NFT development
Hardhat and Foundry development workflows

All seven sessions have been completed and submitted.
