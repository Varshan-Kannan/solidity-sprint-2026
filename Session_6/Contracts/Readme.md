## Objective

The objective of this session was to build an NFT collection using OpenZeppelin's ERC-721 implementation. The contract supports unique NFTs, metadata URI storage, and restricted NFT creation.

The collection is named **Digital Collection** and uses **DGC** as its token symbol. Only the owner of the contract is allowed to create new NFTs.

## Implementation

The contract uses two OpenZeppelin components:

```solidity
ERC721URIStorage
Ownable
```

`ERC721URIStorage` provides the NFT functionality along with the ability to associate a different metadata URI with individual tokens.

`Ownable` is used to identify the contract owner and restrict the NFT creation function using `onlyOwner`.

## Creating the Collection

During deployment, the ERC-721 name and symbol are initialized:

```solidity
ERC721("Digital Collection", "DGC")
```

The deploying address is also assigned as the initial owner through:

```solidity
Ownable(msg.sender)
```

A private counter named `nextTokenId` is maintained to generate a new ID whenever an NFT is created.

## NFT Creation Process

New NFTs are created through the `createNFT()` function.

The function accepts a metadata URI:

```solidity
function createNFT(string calldata metadataURI)
```

A new token ID is generated by increasing the counter:

```solidity
uint256 newId = ++nextTokenId;
```

The NFT is then safely assigned to the contract owner:

```solidity
_safeMint(owner(), newId);
```

Finally, the metadata location is attached to that NFT:

```solidity
_setTokenURI(newId, metadataURI);
```

The function returns the ID of the NFT that was just created.

## Access Control

NFT creation is protected with:

```solidity
onlyOwner
```

This means that an account that does not own the contract cannot create additional NFTs.

The `owner()` function is also used as the destination address during minting, ensuring that newly created NFTs belong to the current contract owner.

## Checking the Collection

The `mintedCount()` function provides the number of NFTs created so far:

```solidity
function mintedCount() public view returns (uint256)
```

For example:

* Before creating any NFT → `0`
* After creating the first NFT → `1`
* After creating another NFT → `2`

The token IDs therefore begin at `1` and increase sequentially.
